# cto-contest
Repo for CTO-Contest 

## Задача: "Пост во все социальные сети."
### Уровень: "Задача со звездочкой."

#### Проектирование сервиса.
* В реализации задачи я использовал язык Python3 и библиотеку requests.
* Это будет десктопное приложение, для запуска которого необходимо выполнить питоновский скрипт. Приложение отправляет простой пост или пост с картинкой в социальные сети VK и Facebook.
* Результатом выполнения приложения является публикация постов сразу в двух социальных сетях и ответ одного из следующих видов: 
```
Пост успешно опубликован в VK! ✅

Пост успешно опубликован в Facebook! ✅

Возникли ошибки! Пост не был опубликован в VK. ❌

Возникли ошибки! Пост не был опубликован в Facebook. ❌

Введено некорректное значение. ❌
```

  Все ответы на запросы, реализованные с помощью API, приходят в формате json. Например,  на запрос
```python
responseToGetPhotoServer = requests.get(requestToGetPhotoServer),
```
  который должен вернуть адрес для сохранения картинки, ответ будет выглядеть так:
```
{'response': {'album_id': -14, 'upload_url': 'https://pu7-8.vk-cdn.net/c854024/upload.php?act=do_add&mid=498534285&aid=-14&gid=0&hash=e2e8162fa9ee1d90e915814ab63c0c14&rhash=0def90ae7b11909534430e542785c471&swfupload=1&api=1&wallphoto=1', 'user_id': 498534285}}
```
* Видео с примером работы и подробным описанием кода находится в этом же репозитории с названием *red-cto-contest.mp4*.
* **Сервис, реализованный в виде десктопного приложения, который позволяет пользователю выбрать тип поста (простой текстовый пост *(тип 1)* или пост с картинкой *(тип 2)*).**
  <br> 1. Пользователь приложения вводит 1 или 2 в зависимости от типа создаваемой публикации.
  <br> 2. Приложение предлагает пользователю ввести текст поста и имя картинки с указанием пути к ней в локальном хранилище (если пользователь выбрал создание поста с картинкой). В случае, если картинка находится в том же разделе, можно просто ввести имя картинки.
  <br> 3. Приложение генерирует и отправляет запросы, используя api социальных сетей.
  <br> 4. В случае поста с картинкой необходимо сначала загрузить её на сервер, используя методы загрузки, описанные в api -- приложение делает всё автоматически.
  <br> 5. Когда все необходимые запросы сформированы, приложение отправляет запросы на публикацию в VK и Facebook, используя методы, описанные в api социальных сетей.
  <br> 6. Полученные ответы сообщают об успешности или невыполнении публикации.
  <br> 7. Приложение выводит соответствующие текстовые уведомления об успешности публикации.
* Для запуска программы необходимо в файле *posting.py* ввести нужные токены доступа и ссылки на страницы (места кода, где это необходимо сделать, указаны), затем терминале выполнить команду. (Сейчас все токены заведомо испорчены).
```bash
python3 posting.py
```
